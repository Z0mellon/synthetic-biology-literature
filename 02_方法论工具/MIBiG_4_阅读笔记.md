# MIBiG 4.0：实验验证 BGC 的参考数据库

> 阅读状态：未开始

## 阅读问题

1. 一个 BGC 满足什么标准才能进入 MIBiG？
2. MIBiG 记录了哪些证据、基因功能与产物信息？
3. 4.0 的新增内容解决了什么数据质量或覆盖度问题？
4. 数据库匹配很像时，哪些结论可以说，哪些不能说？

## 与 antiSMASH 的关系

| antiSMASH | MIBiG |
| --- | --- |
| 从新序列中提出候选 BGC | 提供经过实验验证的参考条目 |
| 预测与相似性提示 | 支撑比较和注释，但不替代实验 |
